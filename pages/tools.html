EVChargeAdvisor-AI

Global EV Charging Infrastructure Equity Analysis Platform

A comprehensive AI-powered platform for analyzing electric vehicle charging infrastructure equity across the globe. Integrates data from OpenChargeMap, US Census Bureau, and World Bank APIs with LLM-powered insights through Groq API.

ParkSense-AI

Real-Time Parking Analysis for Singapore

An intelligent parking analysis platform processing real-time data from 2,581 carparks across Singapore's three major agencies (HDB, LTA, URA). Features natural language explanations powered by AI for intuitive understanding of parking patterns.

2,581 carparks monitored
Multi-agency data integration
Natural language AI explanations
Predictive availability modeling
Python Streamlit LLM API REST APIs
